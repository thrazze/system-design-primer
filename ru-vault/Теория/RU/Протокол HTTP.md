### Протокол передачи гипертекста (HTTP)

HTTP — это метод кодирования и передачи данных между клиентом и сервером. Это протокол запрос/ответ: клиент отправляет запросы, а сервер отвечает нужным содержимым и информацией о статусе завершения запроса. HTTP самодостаточен (self-contained) — запросы и ответы могут проходить через множество промежуточных маршрутизаторов и серверов, которые занимаются балансировкой нагрузки, кэшированием, шифрованием и сжатием.

Базовый HTTP-запрос состоит из глагола (verb, он же метод) и ресурса (endpoint). Ниже перечислены основные HTTP-глаголы:

| Глагол | Описание | Идемпотентен* | Безопасен | Кэшируется |
|---|---|---|---|---|
| GET | Читает ресурс | Да | Да | Да |
| POST | Создаёт ресурс или запускает процесс обработки данных | Нет | Нет | Да, если ответ содержит информацию о свежести данных |
| PUT | Создаёт или заменяет ресурс | Да | Нет | Нет |
| PATCH | Частично обновляет ресурс | Нет | Нет | Да, если ответ содержит информацию о свежести данных |
| DELETE | Удаляет ресурс | Да | Нет | Нет |

*Можно вызывать многократно без разных результатов.

HTTP — протокол уровня приложения, который опирается на протоколы более низкого уровня, такие как **TCP** и **UDP**.
