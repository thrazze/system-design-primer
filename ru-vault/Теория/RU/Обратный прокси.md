# Обратный прокси (веб-сервер)

<p align="center">
  <img src="../../../images/n41Azff.png">
  <br/>
  <i><a href=https://upload.wikimedia.org/wikipedia/commons/6/67/Reverse_proxy_h2g2bob.svg>Источник: Wikipedia</a></i>
  <br/>
</p>

Обратный прокси — это веб-сервер, который централизует внутренние сервисы и предоставляет внешнему миру единый интерфейс. Запросы клиентов пересылаются на сервер, способный их обработать, а обратный прокси уже возвращает клиенту ответ этого сервера.

Дополнительные преимущества:

* **Повышенная безопасность** — скрывает информацию о бэкенд-серверах, позволяет вносить IP в чёрный список, ограничивать число соединений на клиента
* **Повышенная масштабируемость и гибкость** — клиенты видят только IP обратного прокси, поэтому серверы можно масштабировать или менять их конфигурацию незаметно для внешнего мира
* **SSL termination** — расшифровка входящих запросов и шифрование ответов сервера, чтобы бэкенд-серверам не приходилось выполнять эти потенциально дорогие операции
    * Отпадает необходимость устанавливать [сертификаты X.509](https://en.wikipedia.org/wiki/X.509) на каждый сервер
* **Сжатие** — сжимает ответы сервера
* **Кэширование** — отдаёт ответ на закэшированные запросы
* **Статический контент** — раздаёт статику напрямую
    * HTML/CSS/JS
    * Фотографии
    * Видео
    * И так далее

### Балансировщик нагрузки vs обратный прокси

* Балансировщик нагрузки полезен, когда серверов несколько. Часто балансировщики распределяют трафик по набору серверов, выполняющих одну и ту же функцию.
* Обратный прокси может пригодиться даже при одном веб-сервере или сервере приложения — раскрывая преимущества, описанные выше.
* Такие решения, как NGINX и HAProxy, умеют совмещать функции обратного прокси уровня L7 и балансировщика нагрузки.

### Недостатки: обратный прокси

* Добавление обратного прокси увеличивает сложность системы.
* Один обратный прокси — единая точка отказа; настройка нескольких прокси (то есть [переключение при отказе (failover)](https://en.wikipedia.org/wiki/Failover)) ещё больше усложняет систему.
