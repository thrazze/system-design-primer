## ❓ Самопроверка

- [ ] Выбери три задачи из списка и для каждой набросай план ответа по каркасу собеседования — без деталей, только шаги.
- [ ] Разбери источник по Dropbox: как устроена синхронизация файлов и как решаются конфликты версий?
- [ ] Изучи rate limiter у Stripe: какие алгоритмы ограничения частоты запросов там описаны?
- [ ] Сравни ленту новостей Facebook и трендовые темы Twitter: где push-модель, а где pull?
- [ ] Почему для генерации ID (как в Snowflake) не подходит обычный auto-increment из одной базы?
